## 7. Ответы на вопросы дизайна

**a) Тип реквизита «Вид работы» в ТЧ МеханизированныеРаботы техкарты:**
`ВидРаботы : CatalogRef.ВидыРаботСотрудников` (справочник без префикса Апк, `Catalogs/ВидыРаботСотрудников/ВидыРаботСотрудников.xml`). Дополнительно в ТЧ есть `ХарактеристикаРаботы : CatalogRef.АпкХарактеристикиВидовРабот` и служебный `ТипРаботы : xs:decimal`.

**b) Ссылка на конкретное ТС или модель в ТЧ карт на поле:**
Только МОДЕЛЬ, не конкретная единица ТС. В ТЧ `МеханизированныеРаботы`: `Техника : CatalogRef.АпкМоделиСХТехники`, `Оборудование : CatalogRef.АпкМоделиСХОборудования`. В ТЧ `ТранспортныеРаботы`: `Автомобиль : CatalogRef.АпкМоделиАвтотранспорта`, `Прицеп : CatalogRef.АпкМоделиПрицепов` (в регистрах измерения так и называются). Конкретное ТС (`Catalog.ТранспортныеСредства`) в техкартах не хранится.

**c) Реквизиты госномера/подразделения у справочника ТС (`Catalogs.ТранспортныеСредства`, иерархический, группы+элементы):**
- Госномер/номера: `АпкХозНомер` (инвентарный/хоз. номер, string), `АпкНомерVIN`, `АпкНомерДвигателя`, `АпкНомерКПП`, `АпкНомерКузова`, `АпкНомерШасси`, `ЛицензионнаяКарточкаРегистрационныйНомер`. Отдельного реквизита «ГосНомер» нет — фактически используется `АпкХозНомер`/VIN.
- Тип/модель: `Тип : CatalogRef.ТипыТранспортныхСредств`, `АпкТипТС : EnumRef.АпкТипыТС`, `АпкМодель : (АпкМоделиАвтотранспорта | АпкМоделиПрицепов | АпкМоделиСХОборудования | АпкМоделиСХТехники)`.
- Подразделение-владелец: в шапке живого реквизита НЕТ — есть `УдалитьАпкЭксплуатирующееПодразделение : CatalogRef.СтруктураПредприятия` и `УдалитьАпкПодразделениеЗатрат` (помечены на удаление, т.е. в АПК 2.5 текущей версии владение через них не ведётся). Владелец: ТЧ `АпкВладельцы` (колонка `Партнер : CatalogRef.Партнеры`) и `УдалитьАпкВладелецТС`. Есть `АпкПринадлежность : EnumRef.АпкПринадлежностьТС`, `АпкГруппа : CatalogRef.АпкГруппыТранспортныхСредств`, `АпкМестоПарковки : CatalogRef.АпкТочкиМаршрута`. Для «доступности по подразделениям» в разрабатываемом расширении потребуется свой регистр/реквизит связи ТС↔подразделение.

**d) Регистраторы и измерения АпкМеханизированныеРаботыПоГодовомуПлану:**
Регистраторы: `Document.АпкТехнологическиеКартыНаПоле` и `Document.КорректировкаРегистров`. Вид: обороты (Turnovers). Измерение с техникой ЕСТЬ, но называется `Техника : CatalogRef.АпкМоделиСХТехники` (не «МодельТехники»); также `Оборудование : CatalogRef.АпкМоделиСХОборудования`. Ключевые измерения: СценарийПланирования, Организация, Подразделение, Поле, Культура, ГодУрожая, Технология, ПериодНачала/ПериодОкончания (dateTime), ВидРаботы, ХарактеристикаРаботы, Техника, Оборудование, ЕдВСцепке, МаркаТоплива, КлючСвязи/КлючСвязиОсновнойРаботы. Ресурсы тройные (…_Мин/_Вер/_Макс): Гектаров, Тонн, Смен, Часов, УЭГ, ДопОбъемРабот, РасходГСМ, ОсновнаяЗП, ДополнительнаяЗП, Отпускные, ИтогоЗП.

**e) Существующие объекты про дефицит/доступность/занятость:**
Найден один: `InformationRegisters/АпкРасчетОбеспеченности_Дефицит.xml` (регистр сведений «Расчет обеспеченности_Дефицит», поля: Количество, ЕдиницаИзмерения, КлючСвязиПотребности). Отдельных отчётов/регистров «Дефицит техники»/«Занятость техники» в составе расширения нет — тема свободна для нового расширения.

**f) Формы документа АпкТехнологическиеКартыНаПоле (относительно `Documents/АпкТехнологическиеКартыНаПоле/`):**
- `Forms/ФормаСписка.xml` (+ `Forms/ФормаСписка/Ext/Form/…` — единственная собственная форма; формы документа/элемента нет, используется автогенерируемая)
