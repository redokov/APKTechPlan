Шапка: Организация, ПредставлениеПодразделений, СценарийПланирования, Комментарий, Автор.
Табличные части:

| Часть | Колонки |
|---|---|
| Подразделения | Подразделение (Справочник.СтруктураПредприятия) — многострочная |
| Техника | ТранспортноеСредство — только |
| Оборудование | ТранспортноеСредство — только |

Ключевые факты: **нет** признака «Принят», **нет** «Количество», **нет** «МодельТехники»

а списком в отдельной табличной части; пятая категория «Прицепы» существует только здесь.

Образец данных: проведённый документ, ТЧ Подразделения — 1 строка, ТЧ Техника — 4 машины,
остальные части пусты.

## Что читает код сегодня: Документ.Тх_ПланТехническихРесурсов (расширение)

Шапка: Организация, **Подразделение** (одно, в шапке), СценарийПланирования, Комментарий.
Табличные части (строки): ОсновнаяТехника (ТранспортноеСредство, МодельТехники, Принят,
Количество, ПотребностьСмен, ПотребностьЧасов, ДоступноЕдиниц, Оборудование, ВидРаботы,
Комментарий), Оборудование (ТС, Модель, Принят, Количество), Автотранспорт (ТС, Модель,
Принят, Количество + дубль колонок потребности).

## Вывод

Текущий запрос доступности читает документ расширения, а утверждённый источник —
документ основной конфигурации (решения D-006/TD-007 спецификации 002). Структурная
замена не «точечная»: чтение надо перестраивать — категории по табличным частям
утверждённого документа, модель — через справочник ТС, список подразделений — из
многострочной части, признак «Принят» и «Количество» в источнике отсутствуют.
Категория «Прицепы» не имеет значения в перечислении видов техники расширения.


## Дополнено 2026-11-09 (после решений владельца по вопросу 2)

- Потребность: регистры оборота годового плана (АпкМеханизированныеРаботыПоГодовомуПлану,
  АпкТранспортныеРаботыПоГодовомуПлану) заполняются из документов
  АпкТехнологическиеКартыНаКультуру; измерения включают организацию, подразделение,
  поле, период (начало/окончание), вид работы, технику/оборудование (модели),
  автомобиль/прицеп; ресурсы — смены/часы/гектары в трёх вариантах объёма (_Мин/_Вер/_Макс).
- Сопоставление моделей: Справочник.ТранспортныеСредства имеет реквизит АпкМодель
  (ссылка на каталог моделей); потребность задаётся моделью из карты, доступность —
  машинами, каждая несёт свою модель.
- Прицеп существует как отдельное измерение потребности (транспортные работы),
  что подтверждает решение считать дефицит прицепов отдельно (V1).
