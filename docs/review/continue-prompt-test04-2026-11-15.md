## Инфраструктура и правила

- Загрузка: `tmp/test04_pipeline.sh` (load → taskkill 1cv8 → агент start → apply →
  genid → юниты; лог `tmp/test04_pipeline.log`). Канон «грабля №3»: после load
  агент ПЕРЕЗАПУСКАТЬ, иначе apply применит старое.
- **Bash-грабля этой сессии**: НЕ собирать `build && pipeline &` одной цепочкой —
  харнесс подвешивает фоновый список, build выполнился ПОСЛЕ загрузки (доказано
  mtime). Build — foreground-вызовом, pipeline — отдельным nohup; после старта
  сверять `stat -c "%y"` исходника и лога пайплайна.
- paramiko-транзиент «Authentication failed» на apply/genid — лечится повтором
  команды (иногда 2 раза), это не авария.
- Агент-дизайнер: `scripts/designer_agent.py start`, команды
  `scripts/designer_agent_cmd.py <файл>` (apply: `scripts/agent_cmd_apply.txt`,
  genid: `scripts/agent_cmd_genid.txt`).
- COM-пробы: `V85.COMConnector`, CONN = `"Srvr='localhost';Ref='dev_erpapk_demo';
  Usr='Администратор (ОрловАВ)';Pwd='';"`. У COM-обёртки нет `agent.Строка` —
  str() в python; `Структура.Получить` через COM тоже недоступен (dynamic binding),
  но внутри 1С это неважно.
- Кириллица в командах — только через UTF-8 файлы (write-инструмент), не printf.
  `PYTHONIOENCODING=utf-8`. Правки BSL — только Python-скриптами с якорями/asserts.
- Правило двух попыток; верификации — самому, без субагентов; модели субагентов
  (если понадобятся) — только `erpband/zai/glm-5.3:NVFP4`.
- Юниты: `scripts/run_unit_tests_com.py` (30 тестов, ~5 мин), VA —
  `tmp/t02_va_all.sh` (~48 мин на 9 фич).
