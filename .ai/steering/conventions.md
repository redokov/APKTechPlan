# Conventions

- Язык артефактов и кода — русский (синонимы объектов 1С на русском).
- Имена объектов расширения — префикс продукта (см. design; предложение: «ТхПл_» или
  осмысленные имена без префикса, т.к. расширение изолировано) — Open Question.
- Расширение НЕ модифицирует типовые объекты: собственные объекты, заимствование форм
  только при необходимости (cfe-borrow), перехваты — только если без них нельзя.
- BSL-код: стандарты ИТС; после правки обязателен гейт bsl-ls до загрузки в базу.
- Кириллица в bash/CLI — только через скрипты-билдеры (scripts/build_cyrillic.py-паттерн),
  не инлайн в команды.
- Все артефакты ночного прогона — на диск (docs/, .ai/sdd/specs/), не в чате.
- SDD: specs нумеруются 001..., статусы draft → approved; nothing is "approved" без
  ревью-гейта (ночью помечаем draft-complete, финальное одобрение — пользователем утром).
- Файлы creds (.its_creds.txt) не коммитить (в .gitignore).
