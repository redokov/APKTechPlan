### Уроки волны 6 (УЧТИ, это проверено на ошибках)

1. **Анализатор Sonar ≠ локальный bsl-ls 1.0.7.** Sonar флагает литералы в
   аргументах `Дата(...)` (2025, 3, 10, 5, 3999, 12, 31) и НЕ флагает литералы
   в простых присваиваниях переменным (`Год = 1999;` чист в срезе). Локальный —
   наоборот, аргументы Дата() exempt. Вывод: дата-хелперы — ТОЛЬКО через
   присваивания Год/Месяц/День (паттерн волны 5). Упрощённые тела
   `Возврат Дата(1999, 12, 31);` в 15 хелперах ТестовыеКонстанты ДАДУТ ~45 новых
   Sonar-замечаний — ОТКАТИТЬ на Год/Месяц/День (конфликт с пунктом 6 ревью
   решён в пользу цели «нулевой OPEN», отразить в отчёте).
2. **NonExportMethodsInApiRegion** (локальный bsl-ls, в Sonar НЕТ): область
   `ПрограммныйИнтерфейс` — только Экспорт-методы. Смешанные области НЕ
   переименовывать — подавление `BSLLS:NonStandardRegion-off/on` вокруг
   `#Область` (проверено, работает и для директив областей).
3. **DuplicateRegion** (локальный Hint): два региона с именем
   `ПрограммныйИнтерфейс`/`СлужебныеПроцедурыИФункции` в одном модуле зажигают
   Hint — по одному стандартному имени на модуль, остальные — подавления.
4. Подавление работает парой: off-комментарий СТРОКОЙ ВЫШЕ диагностики,
   on-комментарий после диапазона. Для мультистрочных запросов — off перед
   `ТекстЗапроса = "ВЫБРАТЬ` и on после закрывающего `";` (диагностика внутри
   строкового литерала, комментарий туда вставлять НЕЛЬЗЯ).
5. `bsl_ls_report.py <src_dir> <out.json>`; MCP `bsl-ls_bsl_analyze`:
   параметр `src` (абсолютный путь), опции `max_issues`, `severities`.
   Вызывать последовательно.
