## Ключевые контракты SRV-02 (для отладки)

- Доступность: проведённые АпкПланТехническихРесурсов сценария; единицы = физические ТС (DISTINCT, дубли не добавляют).
- Приписка: СрезПоследних(ДатаНачала расчёта; пусто → макс. дата проведённого плана сценария) по Организация+ЭксплуатирующеПодразделение;
  машина без записи истории — только общий пул (уровень 2).
- Уровень 1: машины с припиской = (Орг,Подр) строки спроса; уровень 2: остаток из пула по источникам (стабильный порядок,
  перекрёстные организации разрешены B2). Регистр: строка дефицита (источники пустые, два номера) + строки перемещений
  (Источник* = приписка, ПеремещеноСмен > 0). ПланТехресурсовОтсутствует = нет ключа уровня 1 для (Орг,Подр).
- Исправно НЕ используется; тихого fallback нет; основная конфигурация не тронута (кроме чтения её объектов).
- Формирование плана работ: создаёт/перезаполняет АпкПланТехническихРесурсов ФИЗИЧЕСКИМИ ТС (маркер комментария формы
  сохранён), Сводка.СтрокиПлана — деталь (замещение видно там, в документе Комментарий не хранится).
