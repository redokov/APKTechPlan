# APKTechPlan — «Планирование техники АПК»

Расширение конфигурации (CFE) для **1С:ERP АПК** (1С:ERP Управление предприятием +
модуль «Агропромышленный комплекс», ред. 2.5, платформа 8.5): расчёт потребности
в технике по технологическим картам растениеводства и анализ её дефицита.

## Проблема

В технологической карте на поле каждая работа планируется до конкретной модели
техники. Типовой функционал не позволяет:

- сопоставить потребность по техкартам с техникой, доступной подразделению;
- пересчитать объём работы на взаимозаменяемую модель (коэффициенты замещения);
- получить отчёт о дефиците техники по работам/хозяйствам/периодам.

## Что делает расширение (release 1)

| Объект | Синоним | Назначение |
|---|---|---|
| Обработка | Формирование плана работ техники | Автозаполнение документа потребности по данным проведённых техкарт на поле |
| Документ | Потребность в технике | Потребность в моделях техники/оборудования/автотранспорта, корректируемая пользователем |
| Обработка | Расчет дефицита техники | Сопоставление потребности с техникой, доступной подразделению (`АпкПланТехническихРесурсов`) → регистр |
| Отчёт | Анализ дефицита техники | СКД-отчёт по регистру с пользовательскими отборами |
| Регистр | Дефицит техники | Результат расчёта |
| Роли | Тх_Чтение / Тх_Редактирование | Правовой контур, проверен под обычным пользователем ИБ |

Ключевые механизмы:

- **Коэффициенты замещения моделей** — по паспортным реквизитам (ручные:
  УЭГа / ширина обработки / объём бункера / грузоподъёмность → старт по мощности
  двигателя); замещение фиксируется в документе потребности.
- **Контроль совместимости сцепки** — структурная типизация колонок ТЧ +
  серверная валидация `ПередЗаписью` (СХ-техника ↔ СХ-оборудование,
  автотранспорт ↔ прицепы).
- **Нулевое вмешательство в типовые объекты** — расширение не модифицирует
  конфигурацию, обновление основной не ломается.

## Требования к окружению

- 1С:Предприятие 8.5 (проверено на 8.5.4.1683), серверная ИБ.
- Конфигурация-основание: 1С:ERP + модуль АПК 2.5 (объекты `Апк*`).
- Данные: технологические карты на поле (проведённые), план распределения техники
  `АпкПланТехническихРесурсов`, паспортные характеристики моделей.

## Установка

Исходники — в `src/cfe/ПланированиеТехникиАПК/` (XML-выгрузка расширения,
пространство имён MDClasses). Загрузка пакетным Конфигуратором:

```powershell
& "C:\Program Files\1cv8\<версия>\bin\1cv8.exe" DESIGNER `
  /S localhost:<база> /N <пользователь> /P <пароль> `
  /LoadConfigFromFiles "<проект>\src\cfe\ПланированиеТехникиАПК" `
  -Extension "ПланированиеТехникиАПК" /UpdateDBCfg
```

Подробно — `docs/руководство-пользователя.md` (включая подготовку данных и FAQ).

## Разработка и качество

Пайплайн правки (обязателен для каждого изменения):

1. `scripts/pre_load_validate.py` — дешёвая pre-load проверка XML;
2. **bsl-ls** (`bsl_analyze`) + **v8std** — диагностики BSL и стандарты ИТС;
3. загрузка в ИБ (`-Extension … -UpdateDBCfg`);
4. **round-trip verify** — выгрузка обратно и побайтовое сравнение (REAL=0).

Гейты релиза 1: bsl-ls 0 Error, unit 20/20, VA-фичи 01–09 PASS,
round-trip PASS. Права проверяются под обычным пользователем ИБ
(«Агроном»), не под ПолнымиПравами.

## Roadmap (кратко)

- **R2 «Точность расчёта»** — сменные нормы выработки, вариант плана Мин/Вер/Макс,
  автозаполнение оборудования;
- **R3 «Календарь доступности»** — дефицит по датам, занятость до госномеров, Гант;
- **R4 «Межхозяйственные переброски»** — замены техникой других хозяйств холдинга
  с учётом затрат на перемещение;
- **R5 «План-факт и диспетчеризация»** — путевые листы vs план, уведомления;
- **R6 «Экономика и мониторинг»** (опционально) — стоимость закрытия дефицита,
  бюджетирование, ГЛОНАСС-интеграция.

Полная версия: `docs/roadmap.md`.
