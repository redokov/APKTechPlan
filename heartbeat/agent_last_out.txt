$ help config
Использование:

	 config [command] [options]

Общие параметры:

    --version | -v
        получение версии утилиты

Режим:

    config
        Режим работы с конфигурацией

Команды:

    dump-config-to-files (dump-files)
        Выгрузить конфигурацию в XML-файлы

        --dir=<path>
            (обязательный) Путь

        --extension=<extension name>
            Имя расширения

        --all-extensions
            Все расширения

        --update
            Обновить выгрузку (будут выгружены только файлы с версиями, отличающимися от  версий в файле ConfigDumpInfo.xml)

        --get-changes=<path>
            Вывести в указанный файл изменения в текущей конфигурации относительно указанного файла версий

        --config-dump-info-for-changes=<path>
            Файл версий, используемый для вычисления дельты изменений

        --config-dump-info-only
            Выполнить выгрузку только файла версий

        --force
            Выполнить полную выгрузку, если при попытке обновления выгрузки выяснилось, что текущая версия формата выгрузки не совпадает с версией формата, записанной в файл ConfigDumpInfo.xml.

        --list-file=<path>
            Файл, в котором перечислены файлы, которые требуется загрузить. Не используется, если указана опция files

        --threads=<n>
            Количество потоков используемых при выгрузке конфигурации в XML. Не используется при работе с конфигуратором, если не указана опция server

        --archive=<path>
            Упаковать выгружаемые файлы в архив

        --ignore-unresolved-refs
            Не выгружать в неразрешимые ссылки.

        --server
            Обновление будет выполняться на сервере

    load-config-from-files (load-files)
        Загрузить конфигурацию из XML-файлов

        --dir=<path>
            Путь

        --archive=<path>
            Путь к архиву

        --extension=<extension name>
            Имя расширения

        --all-extensions
            Все расширения

        --files=<files>
            Список файлов, которые требуется загрузить. Список разделяется запятыми. Не используется, если указана опция list-file

        --list-file=<path>
            Файл, в котором перечислены файлы, которые требуется загрузить. Не используется, если указана опция files

        --update-config-dump-info
            В конце загрузки в каталоге будет создан файл ConfigDumpInfo.xml, соответствующий загруженной конфигурации.

        --update-config-dump-info-archive=<value>
            Имя файла архива для создания файла ConfigDumpInfo.xml, соответствующего загруженной конфигурации.

        --no-check
            Отключить проверку метаданных конфигурации

        --partial
            Выполнять частичную загрузку файлов конфигурации

        --threads=<n>
            Количество потоков используемых при выгрузке конфигурации в XML. Не используется при работе с конфигуратором, если не указана опция server

    dump-external-data-processor-or-report-to-files (dump-ext-files)
        Выгрузить внешнюю обработку или отчет в XML-файлы

        --file=<file>
            (обязательный) Путь к корневому файлу выгрузки, в который будут сохранены файлы в формате xml внешней обработки или отчета

        --ext-file=<file>
            (обязательный) Путь к файлу внешней обработки (.epf) или отчета (.erf)

    load-external-data-processor-or-report-from-files (load-ext-files)
        Загрузить внешнюю обработку или отчет из XML-файлов

        --file=<file>
            (обязательный) Путь к корневому файлу выгрузки, в который будут сохранены файлы в формате xml внешней обработки или отчета

        --ext-file=<file>
            (обязательный) Путь к файлу внешней обработки (.epf) или отчета (.erf)

    update-db-cfg
        Обновить конфигурацию базы данных

        --dynamic-enable
            Сначала выполняется попытка динамического обновления, если она завершена неудачно, будет запущено фоновое обновление. Значение используется по умолчанию

        --dynamic-disable
            Динамическое обновление запрещено

        --dynamic-restruct-enable
            При выполнении динамического обновления разрешено обновление структуры таблиц БД

        --dynamic-restruct-disable
            Обновление структуры таблиц БД в процессе динамического обновления запрещено. Значение используется по умолчанию

        --warnings-as-errors
            Все предупредительные сообщения будут трактоваться как ошибки

        --prompt-confirmation
            Спрашивать у пользователя подтверждение о принятии изменений при реструктуризации. Если не указан, изменения автоматически подтверждаются. Значение по умолчанию не используется.

        --session-terminate=<disable|prompt|force>
            Завершение активных сеансов в случае необходимости установки эксклюзивной блокировки информационной базы.
            	disable - запрещено (по умолчанию)
            	prompt - запрос пользователя
            	force - принудительное завершение сеансов.

        --session-terminate-message=<value>
            Текст информационного сообщения о причине завершения активных сеансов, которое будет показано на стороне клиента(ов).

        --background-start
            Будет запущено фоновое обновление конфигурации, текущий сеанс будет завершен

        --background-cancel
            Отменяет запущенное фоновое обновление конфигурации базы данных

        --background-finish
            Запущенное фоновое обновление конфигурации базы данных будет завершено: при этом будет наложена монопольная блокировка и проведена финальная фаза обновления

        --background-suspend
            Приостанавливает фоновое обновление конфигурации на паузу. Если фоновое обновление не запущено, будет выдана ошибка

        --background-resume
            Продолжает фоновое обновление конфигурации базы данных, приостановленное ранее

        --server
            Обновление будет выполняться на сервере

        --extension=<extension name>
            Имя расширения

    mobile-app-write-file
        Записать xml-файл мобильного приложения с заданным именем

        --file=<file>
            (обязательный) Путь к файлу

    mobile-client-digi-sign
        Подписать конфигурацию мобильного клиента на основе указанного файла закрытого ключа

        --file=<file>
            (обязательный) Путь к файлу

    mobile-client-write-file
        Записать xml-файл мобильного клиента с заданным именем

        --file=<file>
            (обязательный) Путь к файлу

    dump-cfg
        Сохранить конфигурацию или расширение конфигурации в файл

        --file=<file>
            (обязательный) Путь к файлу

        --extension=<extension name>
            Имя расширения

    load-cfg
        Загрузить конфигурацию или расширение конфигурации из файла

        --file=<file>
            (обязательный) Путь к файлу

        --extension=<extension name>
            Имя расширения

    manage-cfg-support
        Изменить настройки поддержки конфигурации

        --disable-support
            Снять конфигурацию с поддержки

        --force
            Снять конфигурацию с поддержки даже в том случае, если в конфигурации не разрешены изменения. Если не указан, а в конфигурации на момент выполнения команды не разрешены изменения, конфигурация не будет снята с поддержки

    sign-cfg
        Подписать расширение конфигурации цифровой подписью

        --configuration-type=<extension-configuration|extension-db-configuration|extension-configuration-repository|file>
            (обязательный) Тип конфигурации

        --name=<extension name>
            Имя расширения

        --version=<version>
            Версия конфигурации в хранилище

        --file=<file>
            Путь к файлу

        --digi-sign=<file>
            (обязательный) Путь к файлу закрытого ключа

        --signed-file=<file>
            (обязательный) Путь к результирующему файлу

    generation-id
        Получить идентификатор поколения конфигурации

        --extension=<extension name>
            Имя расширения

    extensions
        Подрежим для управления расширениями

                --synonym=<synonym>
                    Синоним в формате функции НСтр()

                --purpose=<customization|add-on|patch>
                    Назначение расширения

            delete
                Удалить расширение

                --extension=<extension name>

                --all-extensions

                        --scope=<infobase|data-separation>
                            Область действия расширения
