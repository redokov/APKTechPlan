# Product

## Что это
Расширение (CFE) для конфигурации «1С:ERP АПК» (1С:ERP Управление предприятием +
модуль «Агропромышленный комплекс», ред. 2.5) — анализ дефицита техники
по технологическим картам растениеводства.

## Проблема пользователя
В технологической карте на поле для каждой работы указывается одна конкретная модель
техники. В хозяйствах есть взаимозаменяемые трактора, но типовой функционал не позволяет:
- сопоставить потребность по техкартам с доступной техникой разных хозяйств холдинга;
- пересчитать объём работы на аналогичную технику (коэффициенты пересчёта);
- получить отчёт о дефиците техники по работам/хозяйствам/периодам.

## Решение (из презентации)
Регистр коэффициентов пересчёта видов работ для разных моделей техники + доступность
техники по отделениям/хозяйствам (с детализацией до госномеров) + отчёт о дефиците.
Хранение основных моделей тракторов, автозаполнение коэффициентов пропорционально
мощности. Расширение не влияет на обновление основной конфигурации, не модифицирует
типовые объекты.

## Адресаты
Агрохолдинги: собственники, топ-менеджеры, агрономы-планировщики.
