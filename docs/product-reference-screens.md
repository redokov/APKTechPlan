## Выводы для требований
1. Хранение коэффициентов пересчёта: период + Работа + Модель техники → коэффициент
   (относительно базовой модели, у которой 1,00).
2. Документ «План технических ресурсов» (доступность техники): Организация +
   Подразделение + Сценарий планирования; три ТЧ (основная техника, оборудование,
   автотранспорт) с детализацией до конкретных ТС (госномер) и признаком «Принят».
3. Отчёт дефицита: агрегированная потребность из техкарт на поле по периодам/работам/
   моделям техники, сопоставленная с доступностью из планов технических ресурсов;
   вывод — количество недостающих смен (количественный дефицит) по подразделению.
4. Дефицит считается в сменах: потребность в сменах по работе на период vs
   доступные смены техники (с учётом коэффициентов пересчёта — во сколько смен
   аналог выполнит тот же объём).
