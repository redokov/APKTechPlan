### Политика правки по правилам (сводка для ворклистов)

| Правило (кол-во) | Как чинить |
|---|---|
| MagicNumber (105) | Число → именованная локальная переменная перед использованием. Даты: `Дата(3999,12,31)` → `Дата("39991231")` (семантика идентична, без MagicNumber; следи, чтобы literal не набрал 3+ повторов → DuplicateStringLiteral). Числа 0/1 обычно не флагаются — чинить только строки из ворклиста. |
| MissingParameterDescription (31) | Добавить `// Параметры:` с описанием каждого параметра (стиль ИТС). |
| MissingReturnedValueDescription (16) | Добавить `// Возвращаемое значение:` с типом и смыслом. |
| NestedFunctionInParameters (28) | Вложенный вызов из аргументов → локальная переменная перед вызовом. |
| Typo (23) | Реальная опечатка — исправить слово (в комментариях и строках; если строка-идентификатор повторяется в модуле — заменить ВСЕ вхождения согласованно). Доменный термин/намеренное слово — не выдумывать: подавить `// BSLLS:Typo-off` с пояснением. |
| YoLetterUsage (20) | «ё» → «е» в комментариях/строках. |
| DuplicateStringLiteral (9) | Повторяющийся литерал → локальная переменная (или модульная константа-область), все места использования — через неё. |
| LineLength (5) | Перенос строки без изменения логики. |
| CodeOutOfRegion (5) / NonStandardRegion (4) | Код вне областей — обернуть в стандартную `#Область … #КонецОбласти` (имена по ИТС: `ПрограммныйИнтерфейс`, `СлужебныеПроцедурыИФункции`, `ОбработчикиСобытий`). Нестандартное имя области (`Тесты_*`) — переименовать в стандартное, содержимое не менять. |
| IfElseIfEndsWithElse (4) | Добавить финальную ветку `Иначе` (недостижимая — `ВызватьИсключение` с пояснением; достижимая — осмысленная обработка). |
| NumberOfValuesInStructureConstructor (4) | Большой `Новый Структура(...)` → создание + `.Вставить()`. |
| IfConditionComplexity (2) | Условие → локальная переменная с говорящим именем или отдельный метод. |
| CognitiveComplexity (2) | Декомпозиция на подфункции (прецедент — волны 2–4), поведение не менять. |
| CommentedCode (1) | Удалить закомментированный код. |
| UnusedLocalVariable (1) | Удалить переменную. |
| ConsecutiveEmptyLines (1) | Убрать лишние пустые строки. |
| DuplicatedInsertionIntoCollection (1) | Повторяющиеся вставки → параметризовать/зациклить. |

Общие принципы: **поведение не менять** (тесты обязаны проходить с теми же
утверждениями и данными); править минимально и точечно; после правки модуль
должен быть синтаксически цел (`КонецФункции`/`КонецПроцедуры` на месте);
строки-идентификаторы менять только согласованно по всем вхождениям.
