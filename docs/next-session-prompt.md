## Грабли (уже наступленные — не повторять)

1. Кириллица в argv bash→powershell/python mangled: всё через python-обёртки (compile_tools.py,
   run_skill.py) или subprocess с юникодом. grep с кириллическими паттернами в bash ненадёжен.
2. 1cv8 DESIGNER с пустым паролем: НЕ передавать голый /P — «съест» следующий аргумент и зависнет
   в интерактивном логине. /P просто опускать.
3. Designer на этой базе ест ~40 ГБ виртуальной памяти: если pagefile мал — tcmalloc-crash и падение
   ragent-сервиса. Если кластер снова упадёт — нужен admin Start-Service; pagefile ≥ 32–48 ГБ.
4. Отчёты/вывод с кириллицей в консоль — mojibake: проверять байты/файлы, не глаза.
5. db-load-xml: powershell-скрипт C:/MyProjects/PiPack/skills/1c/db-load-xml/scripts/db-load-xml.ps1,
   вызывать через run_skill.py; параметры: -V8Path "C:\Program Files\1cv8\8.5.4.1683\bin" -InfoBaseServer
   localhost -InfoBaseRef dev_erpapk_demo -UserName «Администратор (ОрловАВ)» -Password "" -ConfigDir
   <abs path к src/cfe/ПланированиеТехникиАПК> -Mode Full -Extension «ПланированиеТехникиАПК» -UpdateDB.
   «Расширение уже существует» → перезапустить без -UpdateDB, потом с ним.
6. bsl-ls: MCP-инструмент bsl-ls_bsl_analyze (src=абсолютный путь). «0 файлов» = проверка НЕ
   выполнена. Гейт после КАЖДОЙ правки BSL: 0 ошибок. Warnings UnusedLocalMethod на обработчиках
   форм — ложные, если привязка в Form.xml есть (проверять scripts/check_form_handlers.py).
