## §2. Новые дефекты, которых в ревью нет

**2.1b (P0/P1) — детерминированная потеря данных при расчёте по одному виду техники.**
- `Тх_ТехникаСервер/Ext/Module.bsl:1501-1511` `УстановитьОтборыЗапуска`: отбор только `СценарийПланирования` + (если заполнены) `Организация`, `Подразделение`. **`ВидТехники` в отборе нет.**
- `:1397` `НаборЗаписей.Записать(Истина)` — замещение по этому (широкому) отбору.
- `:1407` `Если ЗначениеЗаполнено(ВидТехники) И Стр.ВидТехники <> ВидТехники Тогда Продолжить` — фильтр применяется **после** очистки, только к набору записываемых строк.
- `ВидТехники` всегда передаётся с формы: `Тх_РасчетДефицита/Формы/Форма/Ext/Form/Module.bsl:54`, поле ввода `Form.xml:123`.
- Следствие: запуск с `ВидТехники = Автотранспорт` стирает все строки сценария (включая `СХТехника`) и пишет только автотранспорт.
- Исправление: добавить `Отбор.ВидТехники.Установить(...)` при заполненном `ВидТехники` (или не фильтровать в памяти вообще).

**2.1c (P3) — ревью пропустило инверсию**: `run_unit_tests.py:71` печатает `expected 13 tests, got %d` при реальной проверке `total != 20`. Плюс жёсткий гейт `total == 20` несовместим с введением штатного SKIP (см. §3, шаг 1.3).
