## 7. Риски и стоп-условия

| Риск | Что делать |
|---|---|
| `bsl-ls` показывает ошибки после правки | откатить правку, зафиксировать в fix-log как «не закрыто» |
| `pre_load_validate.py` падает | откатить XML, зафиксировать |
| `db-load-xml` → «Расширение с таким именем уже существует» | сначала загрузить БЕЗ `-UpdateDB`, потом С `-UpdateDB` |
| Round-trip verify показывает `content diff (REAL)` | **БЛОКЕР**: не продолжать, разобраться |
| 429 / биллинг-окно | флаг `cont-after-reset` справится сам |
| `arm-gone` (ttl-expired) раньше конца ночи | **БЛОКЕР**: перевзвод `--repeat N`, если сессия продолжается |
| Завис 1cv8 / база | НЕ убивать через `taskkill` (см. `1c-destructive-ops-guard`) |
