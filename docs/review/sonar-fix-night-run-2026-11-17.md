## 3. Волна 4 — инфраструктура CI

Причина `WARN: Unable to locate 'report-task.txt'` найдена в связке
`jenkins-lib` + конфигурация проекта:

- `src/ru/pulsar/jenkins/library/steps/SonarScanner.groovy` при
  `waitForQualityGate = false` **удаляет `.scannerwork`** в `finally` сразу после
  сканера (`rm -rf %WORKSPACE%/.scannerwork`) — вместе с ним исчезает
  `report-task.txt`, который плагин SonarQube ищет на пост-обработке → WARN;
- и то же условие **не** добавляет `-Dsonar.qualitygate.wait=true`, поэтому
  сборка не ждёт Quality Gate и остаётся SUCCESS при красном гейте.

В проекте стояло `"waitForQualityGate": false`. Исправлено в
`jobConfiguration.json` → **`true`**: сканер сам ждёт гейт
(`-Dsonar.qualitygate.wait=true`, таймаут 90 мин из `timeout.sonarqube`),
блокирует сборку при красном гейте, а `.scannerwork` больше не удаляется —
`report-task.txt` на месте, WARN уходит. Общая библиотека `jenkins-lib`
**не менялась** (её код для `waitForQualityGate = true` корректен) — правка
только в конфиге проекта, чтобы не влиять на остальные пайплайны.
